A processed table (.csv or .tsv): one row per sample or population, a column that says which condition each row belongs to, and the readouts. It is registered privately on this server and the bioinformatics agent can analyse it when a run names it. It is never served over HTTP and never becomes a literature citation.

Analyses that can run

A tool that cannot run here is not offered. That is deliberate: an analysis refused while it is being planned is a decision you can act on, and one that fails half-way through a run is a wasted afternoon.
